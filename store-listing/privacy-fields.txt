SINGLE PURPOSE DESCRIPTION
Park idle Chrome windows on a lightweight page so Chrome Memory Saver can manage the previously selected tab, then return to that tab when the user comes back. Optional immediate discard requests unloading after eligibility checks.

TABS PERMISSION JUSTIFICATION
Read tab URLs, titles and state locally to apply exclusions, identify the previously selected tab, create the temporary parking page, restore that tab later, and request its discard only when the user selects Discard immediately. In the default Let Chrome decide mode, no discard API is called. The Clear parked tabs action restores regular tabs across parked windows and closes only this extension's inactive parking pages after checking a real tab is active. A parking-only window first receives a blank tab to preserve it. It does not read website page contents or transmit browsing information.

STORAGE PERMISSION JUSTIFICATION
Save timing, tab sleeping mode, appearance, site exclusions and other preferences in local extension storage. Store the previous tab's URL, title and position locally for restart recovery, and keep transient window state and individual-tab exclusions in session storage. No Chrome sync storage or external database is used.

ALARMS PERMISSION JUSTIFICATION
Schedule inactivity checks and recover interrupted focus-dwell timers while the Manifest V3 service worker is suspended. Alarms avoid continuous background polling.

DOWNLOADS PERMISSION JUSTIFICATION
Check whether any Chrome download is in progress and temporarily pause parking to avoid interrupting it. The API does not reliably identify a download's source tab, so the safety pause applies to all windows. Download metadata is not retained; the extension does not start, open, modify or delete downloads.

REMOTE CODE
No, I am not using remote code.
All JavaScript and other resources are packaged with the extension. There are no external servers, remotely loaded scripts, or remote executable configuration.

DATA HANDLING EXPLANATION
The extension processes tab URLs, titles, tab/window identifiers, focus/activation state and timing locally for parking, exclusions and restoration. It queries in-progress download metadata only for its safety pause. No user data is sent to the developer or third parties, sold, used for advertising, or used for creditworthiness/lending. There is no telemetry, analytics, account login or tracking service.

DATA-TYPE DISCLOSURES
Web history: disclose local tab URLs and titles used for exclusions and recovery. The extension does not read Chrome's historical browsing database.
User activity: disclose local window focus, tab activation/navigation state and timing used to determine inactivity and a deliberate return. It does not monitor keystrokes, mouse movement or page clicks.
Local processing still involves browsing information. These categories describe the current code; review the dashboard descriptions when completing its data-use checkboxes.

LIMITED-USE CERTIFICATIONS
The current code does not sell or transfer user data; does not use it for purposes unrelated to the stated single purpose; and does not use it for creditworthiness or lending. Confirm the dashboard's certifications after reviewing these practices.
