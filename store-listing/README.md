# Chrome Web Store listing

Everything for the listing lives here:

- `description.txt`: the Store description.
- `privacy-fields.txt`: the Privacy practices tab (single purpose, permission justifications, data use).
- `fields.json`: the other listing fields, the file names in upload order, and the live listing URL.
- Screenshots, promo tiles and the Store icon, generated by [the artwork tools](../tools/store-assets/README.md) from real captures of the extension (`sources/`).
