# Chrome Web Store assets

Listing text, screenshots, promotional images and the Store icon for Chrome Window Parker. `description.txt`, `privacy-fields.txt` and `fields.json` contain the listing copy and metadata.

Final PNGs are generated from the high-resolution masters and source records in `sources/`. Screenshots use the real interface with synthetic tab data. See the [artwork tooling](../tools/store-assets/README.md) for reproduction and verification.
