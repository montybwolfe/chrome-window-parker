# Agent instructions

Read [CLAUDE.md](CLAUDE.md). It is the working contract for any coding agent on this repository: approvals, workflow, invariants, testing and the rules for public files.

The multi-agent workflow this file used to describe, with separate `agent/codex`, `agent/claude` and `agent/ultra` lanes, cross-agent reviews and integration through `dev`, was retired in November 2026. Its records are kept as history: [CLAUDE_AUDIT.md](CLAUDE_AUDIT.md), [CODEX_AUDIT.md](CODEX_AUDIT.md), [ULTRA.md](ULTRA.md) and [ULTRA_AUDIT.md](ULTRA_AUDIT.md).
