# Artwork

- `parker-timer-256.png`, `-512.png`, `-1024.png`: larger copies of the timer from [`icons/parker-timer.svg`](../../icons/parker-timer.svg), for places that need a bigger icon.
- `buy-me-a-coffee-cover-1600x400.png`: the banner for the project's Buy Me a Coffee page, made by [the artwork tools](../../tools/store-assets/README.md) in the same style as the Store artwork. Its essential content stays inside the central 70% in case the banner is cropped.
- `chrome-web-store-badge-no-border.png` and `chrome-web-store-badge.png`: Google's official Chrome Web Store badge (medium), without and with its border, from Google's [branding guidelines](https://developer.chrome.com/docs/webstore/branding). They're unmodified and linked to the listing, as the guidelines require. The README shows the badge without a border on GitHub's light theme, the white background it's made for, and the bordered one (for coloured backgrounds) everywhere else. They belong to Google and aren't covered by this project's licence.

None of these ship in the extension.
